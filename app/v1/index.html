How should you judge the clustering?

  • Internal check, silhouette: higher means points sit closer to their own cluster than to others.
  • Internal check, WCSS: lower means clusters are more compact.
  • External check, adjusted Rand: compares the fitted clusters with known labels when labels exist.

A neat PCA picture alone is not enough. First separate the internal metrics from the external one, then compare both with the visual pattern.

PCA

PCA Variance And Loadings

Medium priority 2025 Q1e

Flow: Understand Week 2 -> drill table reading -> attempt 2025 Q1.

Question: Given eigenvalues and loading columns, identify variance explained and which variables dominate PC1 or PC2.

Tested skill: Read tables, not just plots.

Worked answer

Divide each eigenvalue by the total eigenvalue sum to get the proportion explained. Add proportions for cumulative variance. For loadings, compare absolute values within a PC; the largest absolute loadings are the variables contributing most strongly, with the sign giving direction.

Marking checklist
  • Uses eigenvalue divided by total variance.
  • Mentions cumulative variance when choosing PCs.
  • Uses absolute loading size for contribution.
  • Interprets signs as direction, not importance size.

Common mistake: saying a negative loading is less important just because it is negative.

Visualisation

PCA, Tours, And Standardisation

Medium priority 2025 Q1a-d

Flow: Understand Week 2 -> write short answer -> check one-mark points.

Question: Explain why a tour can be preferable to a scatterplot matrix, and why PCA should often use standardised variables.

Tested skill: Short answer with one reason per mark.

Worked answer

A scatterplot matrix shows pairwise variable views, while a tour shows changing low-dimensional projections that can reveal structure involving combinations of variables. PCA should be standardised when variables use different scales because otherwise large-scale variables can dominate the maximum-variance directions.

Marking checklist
  • Contrasts pairwise views with combined projections.
  • States that tours can reveal multivariate structure.
  • States PCA maximises variance.
  • Explains scale domination without standardisation.

Common mistake: describing PCA and tours as the same because both use projections.

Evaluation

ROC-AUC Vs Accuracy

Medium priority 2025 Q2a-b

Flow: Understand Week 3 -> explain threshold logic -> attempt 2025 Q2.

Question: Explain how the ROC curve is produced and why ROC-AUC can be preferable to accuracy.

Tested skill: Threshold logic and model-choice justification.

Worked answer

For every possible probability threshold, convert predicted probabilities into class predictions and calculate the true positive rate and false positive rate. Plot those points to form the ROC curve; AUC summarises the curve. Accuracy uses one threshold, while ROC-AUC checks performance across thresholds.

Marking checklist
  • Mentions predicted probabilities.
  • Mentions all possible thresholds.
  • Names TPR and FPR.
  • Explains one-threshold accuracy limitation.

Common mistake: treating ROC-AUC as accuracy with a different name.

Tuning

Cross-Validation And Hyperparameters

Medium priority 2025 Q2d-e

Flow: Understand Week 3 -> describe CV steps -> choose from validation output.

Question: Describe k-fold cross-validation and how it supports hyperparameter tuning.

Tested skill: Procedural explanation.

Worked answer

Split the training data into k folds. Train on k-1 folds and validate on the held-out fold, repeating until each fold has been held out. Average the validation score for each hyperparameter setting, then choose the setting with the best out-of-sample validation performance.

Marking checklist
  • Defines k subsets/folds.
  • Trains on k-1 folds.
  • Predicts the held-out fold.
  • Compares validation scores across hyperparameters.

Common mistake: using the test set repeatedly during tuning.

Logistic

Logistic Probability Calculation

High priority 2025 Q3a/e

Flow: Understand Week 4 -> calculate probability -> write model form cleanly.

Question: Given beta values and predictors, compute a probability and predicted class.

Tested skill: Formula substitution.

Worked answer

First calculate the score: eta = beta0 + beta1 x1 + beta2 x2 + ... . Convert to probability with p = exp(eta) / (1 + exp(eta)), equivalently p = 1 / (1 + exp(-eta)). Predict class 1 if p is above the chosen threshold.

Marking checklist
  • Correct linear score.
  • Correct logistic transform.
  • Uses the stated threshold.
  • Reports probability and class.

Common mistake: comparing the raw logit score directly with 0.5.

Neural nets

Network Anatomy And Parameters

High priority 2025 Q3b-f

Flow: Understand Week 6 -> count parameters -> critique activation choice.

Question: For p inputs, s hidden units, and one binary output, draw the network and count parameters.

Tested skill: Architecture reading.

Worked answer

With one hidden layer, each hidden unit has p input weights plus one bias, giving s(p + 1). The binary output has s hidden-to-output weights plus one bias, giving s + 1. Total parameters: s(p + 1) + s + 1.

Marking checklist
  • Correct number of input nodes.
  • Correct number of hidden units.
  • Includes hidden-layer biases.
  • Includes output weights and output bias.

Common mistake: forgetting bias terms. Linear hidden activations also collapse the network back to a linear model.

Trees

Gini Split Calculation

High priority 2025 Q4b

Flow: Understand Week 5 -> calculate split purity -> compare with marking guide.

Question: Calculate weighted Gini for a proposed classification-tree split.

Tested skill: Hand calculation.

Worked answer

For each child node, calculate class proportions p_k and Gini = sum p_k(1 - p_k), equivalently 1 - sum p_k^2. Weight each child Gini by its sample fraction and add them. A lower weighted Gini means purer child nodes.

Marking checklist
  • Finds left and right class proportions.
  • Calculates each child Gini.
  • Uses child sample weights.
  • Interprets lower Gini as better purity.

Common mistake: averaging child Gini values without weighting by node size.

Tree output

Read An rpart-Style Output

High priority Common 2019/2024

Flow: Understand Week 5 -> read printed output -> compute terminal-node error.

Question: Interpret `n`, `loss`, `yval`, `yprob`, terminal nodes, and training error from printed tree output.

Tested skill: Output reading.

Worked answer

In a node, `n` is the number of observations, `yval` is the predicted class, `yprob` gives class proportions, and `loss` is the count not in the predicted class. Starred nodes are terminal leaves. Training error can be read by summing terminal-node losses and dividing by the total observations.

Marking checklist
  • Defines `n` correctly.
  • Defines `loss` correctly.
  • Uses `yval` as the prediction.
  • Identifies terminal leaves and training error.

Common mistake: treating `loss` as probability rather than a count.

Forests

CART And Random Forests

High priority 2025 Q4c-e

Flow: Understand Week 5 -> explain CART -> justify forest stability.

Question: Describe CART fitting and justify why a random forest can improve on a single tree.

Tested skill: Algorithm explanation.

Worked answer

CART searches variables and candidate split points to optimise a split criterion such as Gini, then repeats recursively until stopping rules are met. Random forests fit many trees on bootstrapped observations and feature subsets, then average or vote across trees, reducing the instability of one flexible tree.

Marking checklist
  • Mentions split criterion.
  • Mentions search over variables and split points.
  • Mentions stopping rules.
  • Mentions many trees, observation subsets, feature subsets, and averaging/voting.

Common mistake: saying forests avoid overfitting only because they are deeper.

kNN

KNN Distance And Vote Probability

Lower priority 2025 Q5d

Flow: Understand Foundations -> sort neighbours -> report probabilities.

Question: Given a test point and training table, compute distances, choose K neighbours, and report class probabilities.

Tested skill: Manual neighbour calculation.

Worked answer

Compute Euclidean distance from the test point to each training point, sort from smallest to largest, and keep the nearest K rows. Without distance weighting, each class probability is its count among the K neighbours divided by K. Predict the class with the largest probability.

Marking checklist
  • Correct distance formula.
  • Correct neighbour ordering.
  • Uses exactly K neighbours.
  • Reports probabilities as counts divided by K.

Common mistake: counting all nearby-looking points instead of exactly K neighbours.

XAI + SVM

SVM Cost And SHAP Interpretation

Lower priority 2025 Q5b-c

Flow: Understand Weeks 7-8 -> define terms -> justify from plot wording.

Question: Interpret SVM cost/margins/support vectors and define a SHAP value.

Tested skill: Model interpretation language.

Worked answer

A larger SVM cost penalises margin violations more strongly, usually giving a narrower margin with fewer tolerated mistakes. Support vectors are the points that determine the margin. A SHAP value is a local feature contribution, comparing predictions with and without a feature while averaging over possible subsets of the other features.

Marking checklist
  • Connects larger cost to stronger penalty for violations.
  • Identifies support vectors as margin-defining points.
  • Defines SHAP as local feature contribution.
  • Mentions averaging over feature subsets/coalitions.

Common mistake: saying SHAP is just ordinary global feature importance.

Clustering

K-Means And Single Linkage

High priority 2025 Q6b-c

Flow: Understand Week 9 -> do one iteration -> draw dendrogram heights.

Question: Perform one k-means update and construct a small single-linkage dendrogram from distances.

Tested skill: Step-by-step clustering calculation.

Worked answer

For k-means, assign each observation to the closest current centre, then update each centre to the mean of its assigned points. For single linkage, merge the closest pair or clusters first; cluster-to-cluster distance is the minimum distance between any member pair. Dendrogram heights are the merge distances.

Marking checklist
  • Calculates distances to current k-means centres.
  • Updates centres using assigned-point means.
  • Uses minimum pairwise distance for single linkage.
  • Labels dendrogram merges with correct heights.

Common mistake: using average or complete linkage while the question asks for single linkage.
